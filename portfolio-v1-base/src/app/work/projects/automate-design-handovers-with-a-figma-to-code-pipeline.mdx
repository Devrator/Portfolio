## My Internship at Xebia (Coding Role)

From June to July 2025, I worked as a **Data Engineering Intern at Xebia**, focusing on building and managing scalable data pipelines using industry-standard tools.

### 💼 Responsibilities

- Designed and optimized **ETL pipelines** using **Apache Spark**
- Implemented and tracked machine learning models using **MLflow**
- Built and executed **Databricks notebooks** for large-scale data processing
- Integrated **Spark transformations and actions** into daily workflow
- Worked with real-time and batch data architectures

### 🛠 Tools & Technologies

- Apache Spark  
- Databricks  
- MLflow  
- Python (PySpark)  
- Git & GitHub  

### 🚀 Outcome

This internship gave me strong hands-on experience with modern data platforms and cloud-native ML workflows. It enhanced my coding, debugging, and real-world problem-solving abilities within a production-grade data environment.
